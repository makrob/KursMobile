# Приложение KursMobile
## Описание
Приложение отображающие прогноз погоды для выбранного списка городов

### Источник данных
Источник данных:
- Open-Meteo для прогноза https://open-meteo.com/en/docs#latitude=59.94&longitude=30.31&hourly=temperature_2m&forecast_days=16 
- Api-Ninjas для определения координат по названию города https://api-ninjas.com/api/city
