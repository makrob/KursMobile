# Приложение KursMobile
## Описание
Приложение отображающие прогноз погоды для выбранного списка городов

### Источник данных
Источник данных:
- Weather Api для прогноза погоды:- https://api.weatherapi.com/v1/forecast.json?key={{api_key}}&q={{latitude,longitude}}&days={{days}}
- Api-Ninjas для определения координат по названию города: https://api.api-ninjas.com/v1/city?name={{cityName}}
